
# Quest Master

A powerful Discord bot dashboard for managing quests, economy, XP, rewards, and community progression.

## Features

- Economy and daily rewards
- Quests and claimable rewards
- XP and leveling system
- Leaderboards and user profiles
- Discord server dashboard
- Statistics and bot information

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Node.js
- Express
- Discord OAuth2

## Development

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build the website:

```bash
npm run build
```

## Security

Never publish Discord bot tokens, client secrets, or private API keys.
